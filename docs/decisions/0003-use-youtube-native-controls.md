# ADR-0003: YouTube埋め込みプレイヤーの標準操作を使う

## Status
Accepted — 2026-11-11 ユーザー確認。

## Context
動画の基本操作をアプリ独自のUIへ一本化する案がBDDに残っていたが、
ユーザーは埋め込み操作の無効化と自作UIを取りやめた。
現在のPlayerSectionも標準操作を無効化する指定やクリック遮断層を持たず、
字幕・音量・全画面などの自作操作UIを設けていない。

## Decision
再生・一時停止・字幕・音量・ミュート・全画面はYouTube埋め込みプレイヤーの標準操作を使う。
アプリは埋め込みのコントロール、キーボード操作、直接クリックを無効化しない。
これらの基本操作を置き換える自作UIは設けない。
区間編集用のシークバー・マーカー・区間再生と、プレイリストの「すべて再生」は維持する。

## Alternatives
- 埋め込み操作を無効化し、基本操作を自作UIへ一本化する。採用しない。
- 埋め込みの標準操作を使い、アプリは区間編集とプレイリスト操作を提供する。採用する。

## Reason
標準の動画操作は埋め込みプレイヤーへ任せ、区間編集とプレイリスト操作をアプリの役割とする。
基本操作の制限や自作UIの有無は設計上の選択であるため、否定だけのBDDではなくこのADRへ記録する。

## Consequences
- BDDには再生・一時停止・連続再生・区間編集など、利用者が操作した際の振る舞いを残す。
- 字幕などの標準機能の利用可否はYouTubeと動画側の条件に依存する。
- 方針の確認と実動画での動作検証は区別する。実動画の自動再生・一時停止は引き続き未検証。
